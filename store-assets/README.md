# Google Play ストア掲載用アセット

Google Play Console の「ストアの掲載情報のメイン」で使用する画像アセットです。

| ファイル名                | 推奨用途                                           | サイズ         |
| :------------------------ | :------------------------------------------------- | :------------- |
| `feature-graphic.png`     | フィーチャー グラフィック（ヘッダー看板）          | 1024 × 500 px  |
| `screenshot-1-keyart.png` | スクリーンショット 1枚め（キービジュアル）         | 1080 × 1920 px |
| `screenshot-2-list.png`   | スクリーンショット 2枚め（連続スキャン・一覧）     | 1080 × 1920 px |
| `screenshot-3-detail.png` | スクリーンショット 3枚め（詳細確認・エクスポート） | 1080 × 1920 px |

※ アプリアイコン（512 × 512 px）は `public/icon-512.png` を使用します。
